# InsightCart - E-commerce Analytics Platform

## Project Overview

InsightCart is an end-to-end e-commerce analytics project that transforms raw transactional data into meaningful business insights using SQL, Python, and Power BI.

## Objectives

- Analyze sales and revenue performance
- Identify high-performing states and product categories
- Understand customer payment behavior
- Analyze customer review scores
- Identify trends and business opportunities

## Technologies Used

- SQL / MySQL
- Python
- Pandas & NumPy
- Power BI
- DAX
- Git & GitHub

## Dashboard Features

### Executive Dashboard

- Total Revenue
- Total Orders
- Total Customers
- Average Review Score
- Revenue trends
- State-wise analysis
- Product category analysis
- Payment method analysis
- Customer review analysis

### AI Insights

Power BI AI capabilities were used for:

- Key Influencers analysis
- Decomposition Tree for revenue analysis
- Interactive filtering and drill-down analysis

## Key Business Insights

- Identified high-revenue customer states
- Analyzed customer payment preferences
- Examined the relationship between payment installments and revenue
- Evaluated order status and review patterns
- Identified areas for data-driven business improvement
